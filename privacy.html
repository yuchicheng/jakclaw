Privacy policy

Last updated 9 November 2026.

Jak Claw Assistant is a personal tool used only by Yu-Chi (Jack) Cheng. It accesses Gmail, Google Calendar and Google Drive data of the account jakclaw.assistant@gmail.com, and only that account, to send and read that account’s email, create calendar events and invitations, and manage files in Drive folders shared with it.

Data obtained through Google APIs is processed on Jack’s own computer and, only to carry out his requests, by the AI model provider that powers the assistant (Anthropic). It is not sold, not shared with anyone else, not used for advertising, and not used to train machine-learning models. Access tokens are stored locally with owner-only file permissions and can be revoked at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
